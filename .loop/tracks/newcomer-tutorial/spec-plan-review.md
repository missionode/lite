# CP-NEWCOMER-001 — First-time chakra orientation

## Scope

Add a novice-friendly, optional orientation before a normal standard chakra journey when the explicit Returning Journey preference is unchecked. Keep it static and silent so it does not add to active audio or visual workload.

## Behaviour

- Explain the seven centres as a traditional map for reflection, not a medical claim or a required sensation.
- Explain that the user can pause, tune or stop the existing guided journey.
- Start gentle introduction and Skip introduction continue to the existing Arriving path.
- Not now returns to the Lobby without starting the session.
- Returning Journey, demo, Sleep, Music Only and focused practices bypass the orientation.

## Review and evidence

The guard runs before DND, speech unlock, content loading, audio initialization, wake lock and timers. The Standard journey atlas records each branch. Static contracts cover screen, translation, eligibility and start ordering; the targeted browser test covers optional exit and returning bypass. Device readability and playback remain user validation items.
